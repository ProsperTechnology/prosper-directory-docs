Prosper Directory 1.1.0

By Prosper Technologies

Install and import the demo

Use a staging WordPress site with PHP 8.0 or later and an administrator account. Use HTTPS for public accounts and checkout.

  1. Unzip the buyer package. In Plugins > Add New > Upload Plugin, upload and activate prosper-directory-core.zip.
  2. In Appearance > Themes > Add New > Upload Theme, upload and activate prosper-directory.zip.
  3. Open Settings > Prosper Directory and click Import demo. The importer adds nine fictional listings, categories, a submission page, a comparison page and a My Listings dashboard. It skips existing matching slugs. If you already use either page slug, add the appropriate shortcode to your chosen page.
  4. In Settings > General, set your site title. For public signup, enable membership registration and set the new user default role to Subscriber.
  5. In Settings > Permalinks, choose Post name and save. Use Your latest posts under Settings > Reading to show the directory on the homepage. A static homepage displays its own page content.

Run the directory

  • Review submissions under Directory listings. Check the description and destination URLs before publishing.
  • Edit the Website URL, Affiliate URL and Pricing summary in Listing details. The affiliate URL takes precedence when present and displays with a disclosure.
  • Set Best for and Typical workflow to explain how each tool fits into a buyer’s work. These fields appear on listings and comparison pages.
  • Use the featured image as the listing logo. Add or edit directory categories in the WordPress dashboard.
  • Registered members can upvote and post a rated review. Use WordPress Discussion settings and the Comments screen for review moderation.
  • Listing owners can use My Listings to see moderation status, open published listings and check when paid placement expires. The [prosper_listings] shortcode powers the dashboard. Exclude this page from shared full-page caching.
  • Edit the homepage headline and description in Appearance > Customize > Directory homepage.
  • Use [prosper_compare] on a page for side-by-side comparisons of up to three published listings. Use [prosper_submit] on the submission page. The bundled header looks up the compare-tools and submit-a-tool slugs.
  • Deactivating the theme leaves the listings stored by the companion plugin. Export or back up your database and uploads before making production changes.

Enable paid featured listings

  1. Install and configure WooCommerce with a payment gateway. Use classic Cart and Checkout pages with [woocommerce_cart] and [woocommerce_checkout]. Set WooCommerce site visibility to Live so listing owners can reach checkout. Use a test gateway first.
  2. Create a published Simple product, mark it Virtual, set a positive regular price, and set catalog visibility to Hidden. Copy its product ID.
  3. Enter that ID under Settings > Prosper Directory.
  4. Sign in as the owner of a published listing. Select Feature for 30 days on the listing page and complete a test payment. Confirm the listing displays a Featured badge and appears ahead of regular results.
  5. For refunded or disputed orders, remove the listing's _pd_feature_until post meta if you need to revoke placement. Refunds do not automatically remove placements.

Staging acceptance checks

Check a fresh install and repeat demo import. Test signup, front-end submission, admin approval, category filtering, search, a repeat upvote, a moderated rated review, three-tool comparison, affiliate links and the mobile layout. For payments, test a successful order, an abandoned order, a different account attempting to feature the listing, and the expiry of a paid placement. Capture product screenshots from the verified installation.

The demo is fictional. Other directory niches can reuse the plugin and taxonomy. The included storefront copy is written for AI tools.
